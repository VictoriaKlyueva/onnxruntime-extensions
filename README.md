# ONNX Runtime Extensions - Contribution by Victoria Klyueva

## Описание вклада

В этом проекте я внесла вклад в open source решение - библиотеку для оптимизации и инференса моделей ONNX Runtime Extensions от Microsoft, добавив функциональность постпроцессинга для модели YOLO. Основная цель моего вклада — упрощение и стандартизация процесса получения bounding boxes (ограничивающих рамок) из raw outputs модели в удобном для дальнейшей обработки формате. Была обновлена документация части проекта с описанием нового функциона. Мой pull request был принят и попал в production версию.
